# public/assets/seals/

One image per hand sign, `<id>.png` (ids from `shared/handSigns.ts`):
rat ox tiger hare dragon snake horse ram monkey bird dog boar mizunoe gassho.

Shown in the **Seal Guide** (press **G** in battle), the on-screen seal pad, and
the seal HUD. Missing files fall back to the kanji character automatically
(`src/ui/sealVisual.ts`).

## Current images

The 14 PNGs here are the reference photos from the "印の種類" table in
[Kazuhito00/NARUTO-HandSignDetection](https://github.com/Kazuhito00/NARUTO-HandSignDetection)
(Apache-2.0), downsized to 220 px. Swap in your own — same filenames — to restyle.
